# GitHub Workflow Demo: Facilitator Handoff

This document is the entry point for the new-hire GitHub workshop. It walks the facilitator through the repo's current state and the three hands-on exercises participants will complete.

## The three exercises

1. **Exercise 1: Open a practice issue** — Each participant opens a small, clearly titled issue describing a task, practicing good issue hygiene (tracked in issue #2).
2. **Exercise 2: Submit a practice pull request** — Each participant creates a branch, makes a small change, pushes it, and opens a PR into `main` (tracked in issue #3).
3. **Exercise 3: Leave a practice review** — Each participant leaves a review comment on the open PR in this repo, practicing review etiquette (tracked in issue #4).

All three exercises are attached as sub-issues of the parent issue **"Workshop prep: participant exercises"** (#1).
