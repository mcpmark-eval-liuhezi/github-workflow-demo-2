# Contributing to the workflow demo

Welcome! This repo is a sandbox for the new-hire GitHub workshop, so the bar for changes is intentionally low — but a few basic ground rules keep the demo tidy and give everyone the same experience.

- **Work on a branch, not `main`.** Create a short-lived branch with a descriptive name (for example `add-cool-thing`) and make your changes there.
- **Small, focused changes.** One idea per pull request. Small diffs are easier to review and easier to explain during the workshop.
- **Write a clear PR title and description.** Say what changed and why, in a sentence or two.
- **Let someone review before merging.** Reviews are the point of the exercise — expect at least one comment before anything merges.
- **Be kind.** Feedback should be about the change, not the person. If something looks odd, ask a question before assuming it's wrong.
- **It's a throwaway repo.** Feel free to experiment, break things, and ask questions. Nothing here is precious.

Thanks for helping make the workshop a smooth one!
